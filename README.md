# WPS DOCX LaTeX 公式转换器

一个本地优先的网页工具，将 WPS/Word `.docx` 文档中的常见 LaTeX 公式代码批量转换为 Word/WPS 可编辑的 Office Math（OMML）公式。

## 内容

- `webapp/`：Web 应用源代码。
- `outputs/公式转换器（双击打开）/`：无需安装环境、可直接在浏览器打开的离线版本。

文档只在浏览器本地处理，不会上传到外部服务。为保护隐私，测试文档、转换后的 `.docx` 文件和临时工作文件未纳入仓库。

## 使用

请查看 [webapp/README.md](webapp/README.md) 获取功能范围与本地开发说明；若只需使用转换器，可直接打开 `outputs/公式转换器（双击打开）/index.html`。
