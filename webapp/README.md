# 公式转换器

一个本地优先的网页工具：在浏览器中把现有 DOCX 文档里的常见 LaTeX 公式代码转换为 Word/WPS 可编辑的 Office Math（OMML）公式。

## 使用方式

1. 在浏览器打开本应用。
2. 选择 .docx 文档。
3. 点击“开始自动转换”。
4. 下载新的 DOCX 文件和 HTML 转换报告。

文档仅在浏览器中读取和处理，不会上传到外部服务。原文件不会被覆盖。

## 首版支持

- 行内和独立公式标记：$...$、$$...$$、\\(...\\)、\\[...\\]
- 上下标、分式、根号、常用希腊字母
- 求和、乘积、积分、极限、常见运算及关系符
- 矩阵、分段函数及常用上下标重音
- 正文、表格、页眉、页脚、脚注与尾注中的普通文字 Run

## 处理原则

- 自动转换识别度高的常见公式。
- 不支持或无法安全替换的内容会保留原文，并写入报告。
- 自定义宏、TikZ、图片/扫描件公式、复杂化学公式和复杂嵌入对象属于后续扩展范围。

## 本地运行

本项目使用 Node.js 22+。安装依赖后运行开发服务器即可。
